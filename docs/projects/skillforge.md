# SkillForge AI

## What the product is for

SkillForge AI is an **AI-native adaptive learning platform** that solves the workflow integration and completion crisis in corporate L&D. Unlike legacy LMS platforms (Coursera, Pluralsight) that force employees to "go somewhere" to learn, SkillForge delivers personalised, real-time skill training directly in the tools engineers already use — **Slack, GitHub, and VS Code** — backed by verifiable credentials. It uses Claude AI for Socratic tutoring (asking questions, not just delivering content) and dynamically adjusts difficulty based on demonstrated comprehension, addressing the problem that 50%+ of users never complete traditional online courses.

## Main customers

- **Primary target:** Tech companies with 50–2,000 employees (SMB to mid-market)
- **Secondary:** Individual developers, data scientists, and DevOps engineers (A$300–600/year willingness-to-pay)
- **Tertiary:** Content creators and L&D teams building proprietary training
- **Pricing model:** B2B SaaS subscription (A$29–A$99/seat/month); AI Course Builder tier (A$99/month); credential verification API
- **Market timing:** A$104B corporate e-learning market growing 21.7% CAGR; Pluralsight distressed; Coursera-Udemy merger imminent (H2 2026)

## Main user cycle

1. **Sign up** — Register via email or OAuth (Google/GitHub); create or join organisation as learner / admin / instructor.
2. **Enrol in course** — Browse AI-generated or instructor-created courses; click enrol; progress tracked immediately.
3. **Complete lessons** — Work through video, text, code exercises, quizzes, or flashcards; AI tutor available for questions (Socratic chat dialogue).
4. **Receive micro-learning** — Slack bot delivers 5-min daily lessons at a configurable time; completable in Slack with real-time progress sync.
5. **Earn credentials** — After achieving 0.8 proficiency on all required skills, receive a W3C Verifiable Credential (signed, publicly verifiable, exportable to PDF/LinkedIn).
6. **View org skills graph** — Admin/manager dashboard shows team's skill coverage vs required skills, predictive gaps, and ROI metrics linked to business outcomes.
7. **Share credential** — Learner shares verifiable credential URL or LinkedIn badge; employer can verify via public API endpoint.
